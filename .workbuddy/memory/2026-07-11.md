# 2026-07-11 工作日志

## 已确认问题

1. 初版晚间 OCR 修复只覆盖 `estimate_today`，没有把“当前自然日 OCR”与“相对历史档案较新”拆成两种判定。
2. 周末、节假日和交易日开盘前会把上一交易日 `DailyArchive` 的收益重新标成当前自然日 `official_today`。
3. 收益曲线接口在当前自然日 OCR 存在时可能绕过休市归零，继续构造上一交易日曲线。
4. WebApp 浅色主题仍保留深色半透明小卡；小程序根 `.page` 和 `input` 使用固定深色主题文字色，可能覆盖浅色主题变量。

## 当前修复规则

- `IsOcrSnapshotCurrentForDisplay` 只认北京时间当前自然日；同日 OCR 金额不再叠加任何当日收益。
- 历史归档新鲜度继续由 `IsOcrSnapshotFreshForArchive` 单独处理，两者不得混用。
- `MarketCalendar.ResolveFundDisplaySession` 统一周末、节假日、09:30 前、盘中和收盘后状态。
- 非当前有效交易自然日只承接金额、成本和累计收益，今日收益/率/涨跌幅/曲线归零。
- WebApp 与小程序只保留曜石流光、雾光银蓝两个主题；浅色主题使用深色正文和可读状态色。
