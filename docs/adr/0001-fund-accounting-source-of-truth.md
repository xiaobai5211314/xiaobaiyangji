# 基金金额事实源

## 状态

Accepted

## 背景

项目中存在多个基金金额数据来源：
- **蚂蚁 OCR 快照数据**：用户截图经 OCR 提取后确认的平台展示金额
- **官方净值**：基金公司 T+1 公布的正式净值
- **盘中估值**：东方财富 API 实时抓取的估算值

当多个来源同时存在时，需要同时明确"平台展示事实源"和"正式确认事实源"，避免把买入待确认金额误算进已确认持仓。

## 决策

**蚂蚁 OCR 快照是平台展示金额的最高优先校准源，不是每天唯一的当前金额来源，也不是无条件的正式确认事实源。**

正式确认口径必须先拆分：

```
平台当前金额 = 已确认持仓金额 + 买入待确认金额
```

具体规则：
1. `OcrSnapshotDate` 与北京时间当前自然日相同时，首页当前展示默认使用 OCR 快照中的截图时点金额；盘中估值不得在该金额上重复叠加。若截图后正式净值已经更新，且可靠份额计算出的官方金额与 OCR/滚动金额相差超过 `0.01` 元，则快照已过时，允许按官方金额自愈。跨过 00:00 后旧 OCR 退出当前展示优先级。
2. 无新鲜 OCR 时，首页当前金额必须随官方净值或盘中估值的单基当前市值合计滚动，不能停留在旧 OCR `HoldAmount`。
3. 存在买入待确认金额时，正式确认持仓金额按 `平台当前金额 - 买入待确认金额` 计算。
4. `DailyArchive` 正式档案只能写入已确认持仓金额和已确认收益；买入待确认金额不得进入正式历史确认金额。
5. 首页 summary 的历史字段若仍命名为 `antConfirmedAmount`，语义必须是"确认持仓金额"，不是平台当前金额。
6. 禁止通过 `当前金额 - 昨日收益` 或 `持有收益 - 昨日收益` 等逆推方式构造蚂蚁确认金额。
7. 常规蚂蚁持仓截图不显示真实份额和成本价时，系统可以自动推导辅助字段：份额用官方净值从蚂蚁当前金额反推，成本金额用 `蚂蚁当前金额 - 蚂蚁持有收益` 推导。资产详情页显示 `持仓成本价` 和 `持有份额` 时，成本金额优先按 `成本价 × 份额` 校准；若平台持有收益与 `当前金额 - 成本金额 + RealizedProfit` 存在差额，差额写入 `PlatformHoldingAdjustment`，以保持后续持有收益滚动与平台一致。`RealizedProfit` 只记录确认卖出产生的真实已实现收益，禁止由 OCR 口径差覆盖。派生份额和成本只能服务后续估值、收益率本金和无新鲜 OCR 时的滚动展示，不得覆盖同日 OCR 的当前金额、昨日收益或持有收益。
8. 官方净值清算后的平台展示金额默认按 `上一有效金额 + 已确认收益` 滚动。可靠份额下的 `份额 × 今日净值` 同时作为异常校验线：与滚动值相差不超过 `0.01` 元时不覆盖，相差超过 `0.01` 元时判定旧基数或重复结算异常并以精确值自愈。由普通 OCR 两位金额/净值反推的份额不得触发该覆盖。
9. 单只基金资金流不属于本项目会计事实源。普通场外基金缺少可核验公开实时申赎数据，因此基金级资金流接口和展示已取消；行业板块资金只保留为独立行情参考。
10. 平台展示金额仍以 2 位小数呈现；连续滚动底稿可保留 4 位小数，下一次展示或归档时再统一回到 2 位小数，避免日复一日提前舍入造成分钱漂移。
11. 自然日与有效交易日分离。周末、节假日和交易日 09:30 前允许用上一交易日档案承接金额和累计收益，但当前自然日的今日收益、今日收益率、单基金今日涨跌幅必须为 0；上一交易日档案不得重新标记为 `official_today`。
12. 同一交易日 15:00 前提交的手工买入，在份额确认前只增加 `PendingBuyAmount` 和当前展示金额。`GetDailyBaseAmount`、今日收益率分母、有效份额和 `DailyArchive.Assets` 必须继续使用买入前的确认持仓；正式净值结算后按 `确认基数 + 已确认收益 + 待确认买入` 更新当前展示金额。
13. 份额和成本必须持久化来源与确认状态。资产详情页平台字段和用户手工确认值优先级最高；普通持仓 OCR 从两位金额、官方净值或持有收益反推的辅助值，不得覆盖已有确认值。买入金额/成交净值形成的交易派生份额和成本也不得被普通 OCR 反推值覆盖，只有后续平台详情页或用户手工确认值可以校准。
14. 持有收益与正式归档只能使用确认金额和确认成本。手工买入令未确认 `purchase_amount` 成本暂时包含待确认本金时，确认成本为 `CostAmount - 有效 PendingBuyAmount`，只扣一次；资产详情页/OCR 已确认成本不得再扣。统一公式为 `确认持仓金额 - 确认成本 + RealizedProfit + PlatformHoldingAdjustment`。

## 影响

- `NavSettlementService` 官方净值确认后必须滚动更新当前持仓金额；`DailySettlementService` 归档逻辑必须先检查当日是否有蚂蚁确认。
- `MyFundConfig` 中的 OCR 字段是用户截图的结构化快照，必须保留 pending buy 拆分结果。
- 首页 summary 可以展示平台当前金额，但盈亏日历和收益率本金必须使用确认持仓金额。
- `MyFundConfig.HoldShares` 可能来自资产详情页平台字段或官方净值校准；`CostAmount` 在资产详情页有成本价/份额时按平台字段校准，在截图缺少成本价时可由蚂蚁当前金额和持有收益校准。两者都是辅助账务字段，不是高于蚂蚁 OCR 快照的事实源。
- `MyFundConfig.HoldSharesAreConfirmed`、`HoldSharesSource`、`CostAmountIsConfirmed`、`CostAmountSource` 记录辅助账务字段的来源优先级，避免普通 OCR 导入把平台精确值降级为两位金额反推值。
- 可靠精确份额仅包括资产详情页/用户确认份额，以及买入金额与成交净值形成的交易派生份额；普通 `ocr_nav_derived` 份额只能辅助估值，不能触发金额自愈。
- `MyFundConfig.PlatformHoldingAdjustment` 是平台持有收益的中性口径校准字段，不表示卖出或落袋；`MyFundConfig.RealizedProfit` 只由确认卖出流程更新。

## 验收规则

- 有当前自然日 OCR 且尚无更新后的正式净值时，账户总金额与蚂蚁 App 截图当前金额合计一致；盘中估值不得在该金额上再次叠加收益。
- 更新后的正式净值与可靠份额证明截图/滚动金额存在超过 `0.01` 元的基数异常时，`official_today` 应回正为精确金额；持有收益同步按回正后的金额和成本滚动，不再冻结在旧 OCR。
- 到达下一自然日后，旧 OCR 不再锁定当前展示金额；系统从最新确认金额继续滚动。
- 周末、节假日和交易日 09:30 前，账户金额可沿用上一交易日，但今日收益、今日收益率和单基金涨跌幅为 0。
- 无新鲜 OCR 但官方净值或盘中估值已更新时，账户总金额随单基当前市值合计滚动。
- 确认持仓金额等于账户总金额扣除买入待确认金额。
- 份额由普通 OCR 金额/净值自动反推时，有新鲜 OCR 的账户总金额仍以截图金额为准，不允许反推份额覆盖。
- 官方净值清算时，可靠 `份额 * 今日净值` 与 `上一有效金额 + 已确认收益` 相差不超过 `0.01` 元时以后者作为展示和归档金额；差额超过 `0.01` 元时以精确金额自愈。
- 官方净值连续清算时，内部底稿允许保留 4 位小数；同一天重复清算不得因两位展示金额反推而产生新的 0.01 漂移。
- 交易日 15:00 前登记买入待确认后，当天收益必须只按登记前确认持仓计算；当前展示金额可以包含待确认买入，但收益率分母、有效份额和正式归档不得包含该金额。
- 存在待确认买入时，首页持有收益、单基金持有收益和 `DailyArchive.TotalProfit` 使用相同确认成本；不得出现“展示金额含待确认而成本已扣除”或“确认金额已扣待确认而成本未扣除”的相反偏差。
- 资产详情页提供成本价和份额时，成本金额应与 `成本价 × 份额` 对齐，必要时通过 `PlatformHoldingAdjustment` 保持持有收益与平台一致；截图未提供成本价时，成本金额应与 `当前金额 - 持有收益` 对齐。后续无新鲜 OCR 时才用该成本参与持有收益重算。
- 未发生确认卖出时，资产详情 OCR 不得改变 `RealizedProfit`，前端不得出现“已落袋”；确认卖出时 `RealizedProfit` 独立累加，平台校准差不得重复计入。
- 资产详情页确认份额/成本写入后，再导入普通持仓截图，确认值和来源标记保持不变；普通 OCR 不得重新用两位金额反推并覆盖。
- 非确认来源不得覆盖已有的正式档案。
- 当无蚂蚁确认时，系统降级为 `official-nav-pending` 待确认状态，而非使用盘中估值。

## 外部依据

- [中国证监会深圳监管局投资者教育材料](https://www.csrc.gov.cn/shenzhen/c105614/c7602071/content.shtml)：交易日 15:00 前提交按 T 日净值确认，15:00 后视为下一交易日；确认日通常为 T+1，特殊产品可能为 T+2/T+3。
- [华夏基金申购份额查询说明](https://m.chinaamc.com/cjwt/gmwt/5501300.shtml)：普通开放式基金交易日 15:00 前提交视为 T 日申请，通常由登记机构在 T+1 确认；具体产品仍以基金合同和平台实际确认结果为准。
- 富途基金持仓资产说明：基金申购资金在交易确认前未形成持仓份额，会以买入待确认金额形式增加基金持仓金额。
