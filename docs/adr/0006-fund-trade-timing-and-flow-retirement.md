# 基金交易时间与基金级资金流退役

## 状态

Accepted

## 背景

项目曾按基金名称推算普通基金、QDII、FOF 的确认日期，并尝试用场内证券行情接口展示“基金资金流”。审查发现两类边界：

1. 15:00 截止和普通 T+1 可作为通用估算，但特殊基金的开放日、确认日由具体基金合同和平台交易记录决定。
2. 场外基金没有可核验的实时申购/赎回人数或净金额公开源；场内证券主力资金也不能代表场外联接基金申赎。

## 决策

1. 交易时间默认按国内基金销售日历估算：交易日 15:00 前为当日 T，15:00 后或休市日顺延。
2. QDII/FOF 的名称规则只生成“预计确认日”；OCR 或平台交易记录给出的日期优先。
3. 买入待确认份额在交易日官方净值到达后按 `待确认金额 / 交易日净值` 推导；确认日前不进入正式收益份额，确认日后转为有效份额。
4. 未取得实际赎回金额时只登记待确认份额，不提前扣减确认持仓；确认时按原交易日和相同份额结转一次。
5. 删除 `/api/fund/fund-flow`、小程序基金资金流卡片和 WebApp 板块基金弹窗的基金资金流列。
6. 行业/概念板块资金接口继续存在，但只能解释为股票板块行情热度。
7. 删除客户端涨幅清算路由，并让旧盘中估值清算方法退出控制器路由，避免临时估值污染正式档案。

## 外部依据

- 中国证监会深圳监管局：15:00 截止、普通 T+1、特殊产品可能 T+2/T+3，且应以基金合同或公告为准：https://www.csrc.gov.cn/shenzhen/c105614/c7602071/content.shtml
- 《中华人民共和国证券投资基金法》第六十七条：申购、赎回在登记机构确认时生效：https://www.csrc.gov.cn/csrc/c101939/c1045353/content.shtml
- 华夏基金帮助：普通基金、QDII、FOF 的可查询时间并不相同：https://m.chinaamc.com/cjwt/gmwt/5501300.shtml
- 上交所基金市场数据公开的是场内 ETF/LOF 市场规模、成交量、成交额和规模变动，不等同于场外基金实时申赎：https://etf.sse.com.cn/marketdata/

## 验收

- 15:00 前后、国内节假日顺延有回归测试。
- 特殊基金接口文案使用“预计确认日”。
- 待确认赎回不会提前清空持仓，后续确认不会重复扣份额。
- 项目中不再存在 `/api/fund/fund-flow` 请求或基金级资金流文案。
